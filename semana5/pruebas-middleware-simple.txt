Prueba 4: Token incorrecto

Explica qué debería pasar si el token no coincide con el esperado.

5. ¿Qué hace el middleware simple?

Respuesta: El middleware revisa si existe un token y verifica si coincide con el token esperado antes de permitir el acceso a la ruta protegida.

6. ¿Por qué este middleware no debe confundirse con seguridad real?

Respuesta:  Porque es un ejemplo pedagógico y no utiliza métodos avanzados de autenticación, cifrado ni protección real para producción.

7. ¿Qué aprendiste sobre rutas públicas y rutas protegidas?

Respuesta: Aprendí que las rutas públicas pueden ser consultadas por cualquier persona, mientras que las rutas protegidas necesitan validación o autenticación para permitir el acceso.
